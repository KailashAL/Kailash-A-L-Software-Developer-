PROJECT / SSO PHASE II

Single Sign-On (SSO)

Contributed to an enterprise Single Sign-On solution that provides seamless authentication and access across multiple company products. The solution supports Regional Switch, Customer Switch and Profile Switch based on user identity and account information.

🌍 Regional Switch

Allows users to switch between different regional environments from a common SSO experience. Based on the selected region, the user is redirected to the appropriate regional product.

User Login → Select Region → Regional Product

Example: Malaysia → Malaysia HRMS   |   Hong Kong → Hong Kong Product

🏢 Customer Switch

Allows users who are associated with multiple customers or organizations to switch between their available customer environments without logging in again.

Login → Select Customer → Customer Product

Example: A user linked to multiple customer organizations can select the required customer and access that customer's product through the same SSO session.

👤 Profile Switch

Supports users who have multiple profiles associated with the same email address or mobile number. The system identifies the appropriate profile using regional identity information.

MYKAD NRIC HK ID
Email / Mobile → MYKAD / NRIC / HK ID → Profile → Product

Example: The same email or mobile number may be associated with different profiles. The SSO identifies the user's MYKAD / NRIC / HK ID and provides the appropriate profile and product access.
